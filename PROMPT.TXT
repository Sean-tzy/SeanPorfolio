## 7. MOTION + PERFORMANCE

Each section should have its own motion personality:

- Storybook = tactile
- Learning = flowing
- Guardian = precise/reactive
- Skills = systemic
- Beyond Classroom = organic

Avoid repetitive fade-up animations.

**Performance is a hard requirement.**

Prefer `transform` and `opacity`, optimized GSAP timelines, one centralized RAF loop where possible, and IntersectionObserver for activating expensive effects only near the viewport.

Avoid:
- hundreds of particles
- excessive blur
- unnecessary WebGL
- multiple uncontrolled animation loops
- DOM measurements every mousemove
- excessive shadows/filters

Use Three.js only when it genuinely improves the experience. CSS 3D, SVG, Canvas, or layered transforms are preferred when lighter.

Target smooth **~60 FPS** on capable desktops.

Mobile/tablet should use simplified versions of expensive interactions. Respect `prefers-reduced-motion` and preserve keyboard accessibility.
